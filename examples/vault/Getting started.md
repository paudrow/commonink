# Getting started

Common Ink is a local-first notebook: your notes are markdown files on your disk, and your agents work in them with you. Try each thing below. The guide ticks it off as you go, writing into this note the way any agent does, with its name on the change.

- [ ] Type `/` on a new line and add a timer or a task <!-- guide:slash -->
- [ ] Type `@` or `[[` and pick a note to link to it <!-- guide:link -->
- [ ] Press `⌘K` (`Ctrl+K` off a Mac) to search your notes and jump to one <!-- guide:search -->
- [ ] Star this note (☆ at the top), so it stays in your sidebar <!-- guide:star -->
- [ ] Tick a task. Any checkbox will do, even this one <!-- guide:tick -->
- [ ] Watch an agent edit this note, then take the edit back <!-- guide:watch -->

  ::guide{step=watch}

- [ ] Connect your own agent: Claude Code, Claude Desktop, Cursor or any MCP client <!-- guide:connect -->

  ::guide{step=connect}

::guide{step=done}

Markup, embeds, widgets and keys are in [[Tips]].
