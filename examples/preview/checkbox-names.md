title: Task checkboxes have names
---
Try this with a screen reader (VoiceOver: ⌘F5), or check each checkbox's accessible name in the browser's accessibility inspector.

1. In **Notes**, go to the [[Checkbox names]] card. Each checkbox is read with its task, like "Water the plants, checkbox, not checked". Before, it was read as an unlabeled checkbox.
2. Open [[Checkbox names]]. Each box in the editor is "Done, checkbox", and the line's words come after it. Hover a box: it says Mark done, or Mark open if it's ticked.
