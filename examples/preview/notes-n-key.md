title: n for a new note on Notes
---
1. Click Notes in the sidebar. The key line at the bottom of the page now starts with `j k move` and `n new`.
2. Press `n` (not in the filter field). A new Untitled note opens with the cursor in its title, just like the New note button.
3. Go back to Notes and click the **Projects** folder chip. Press `n` again. The new note is made inside Projects.
4. Click in the filter field and type `n`: it just types the letter. Press Esc, then `n` makes a note again.
5. Press `?` for the shortcut sheet. Under Notes page you'll see "n: New note (in the folder you're looking at)".
