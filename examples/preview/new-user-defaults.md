1. Open [[Esc then dd]] and follow it: Vim keys start off, so Esc then `dd` types letters instead of deleting a line. The status bar toggle reads "Vim keys: off" or "on".
2. Go to Notes and scroll to the bottom: "Workspace conventions" (AGENTS.md) sits after your own notes, marked Agent instructions, with a line saying what it's for instead of "You are a guest editor". Open it: a banner says agents read it. Press ⌘K and type "conventions": the badge shows there too.
3. In Notes, type "zebra" in the filter: the empty state names the filter and has Clear filters. If Archived shows 0, click it: it explains archiving and offers Show active notes.
4. Open the account menu and pick New team workspace…. The new workspace's Notes shows the Welcome note first, marked Start here, and Workspace conventions last. Favorites says where a note's star is.
5. In that workspace, select every note with `x` and press `e` to archive them. Notes now shows "No notes yet" with a New note button and no key hints (the filters stay, since Archived has notes in it). Tasks says where tasks come from, with Add a task. Assets (archive margin.svg from its preview first) offers Upload files. In History, pick the AI filter: it offers Show every change.
