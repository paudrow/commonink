title: Writing days
---
1. Open [[Overview]] and scroll to **Writing days**: twelve weeks of squares with today outlined. A new Preview has only today's history, so it says how to start a streak.
2. Type a few words into any note, wait about five seconds, and today's square fills in.
3. Type `/streak` (or "Writing days" in the `/` menu) in a note to add the same heatmap there.
4. The ink-drop chip beside **New note** shows only from a two-day streak, so come back to this Preview tomorrow and write again to see it. Click it for the heatmap, current streak and longest run; Esc closes it.
