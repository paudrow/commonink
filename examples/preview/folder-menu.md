title: Folder actions in a right-click menu
---
1. Hover a folder under **Folders** in the sidebar: only the + (new note) shows now.
2. Right-click the folder: a menu offers New note here, Export as .zip, Share… and Delete….
3. From the keyboard: Tab to the folder and press Shift+F10 (or the Menu key). Use the arrows to move and Escape to close; focus goes back to the folder.
4. At a phone's width (or on a touch screen), the row shows + and ⋯; ⋯ opens the same menu.
