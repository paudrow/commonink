title: Commands in ⌘K and a shortcut sheet
---
1. Press ⌘K (Ctrl+K off a Mac) and type `theme`: a **Commands** section offers **Toggle theme**. Press ↵ and the theme flips. Try `vim`, `archive` or `tasks` too.
2. Type `theme` again with [[Theme ideas]] in the vault: the note stays first and Toggle theme sits under it. A word no note starts with, like `vim`, puts Commands first.
3. Type `>` alone: only commands, each with its shortcut on the right. `>tgthm` still finds Toggle theme.
4. Open [[Command palette notes]], then ⌘K `>`: Star note, Archive note, Move to folder…, History of this note and Open to the side are now offered. Star it and look again: it says Unstar note.
5. ⌘K `getting` offers **Open Getting started**, which opens a note tagged `start` (here [[Palette start note]]).
6. Click somewhere outside the editor (the Notes page) and press `?`: the shortcut sheet opens, grouped Global, Notes page, Editor, Vim, Tasks, Split view. Tab stays inside it, Esc closes it and puts you back where you were. Turn vim off (⌘K `vim`) and the Vim section folds away.
7. ⌘K `new folder` with the Folders section folded: it unfolds and the name field appears.
