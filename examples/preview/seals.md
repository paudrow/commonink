title: Seals for firsts
---
This Preview's sample notes and its guide may already have earned a seal or two, so the first toast can name several. For a clean start, clear `commonink.seals` from local storage and reload.

1. Click **Today** and scroll under the day to **Seals**: one row of seals with a count ("1 of 9"). Earned ones are wax in your ink; the rest are grey dashed rings, each with a line on how to earn it. Check light and dark, and a narrow window (the row scrolls sideways).
2. In any note, type `[[` and pick another note: a toast says **New seal: First link**. Open that other note and click the backlink under it: **New seal: First backlink**. Back on Today, both are in ink.
3. Run **New board** from ⌘⇧P (or `/` → Kanban board) for **First board**, and **New note from template** for **First template**. Save a search as a smart folder from the Notes page for **First smart folder**.
4. Add a task `- [ ] Draft the summary @Claude` to a note: within a few seconds, **New seal: First handoff**. Connect an agent and have it edit a note for **First agent edit**; **Ten agent edits** shows "3 of 10" as they come.
5. Open Settings (⌘,) → **Workspace → Unlock as you go** and turn it off. Seals leave the Today page, and doing something new (another board, say) brings no toast. Turn it back on: the seals you'd earned are still there.
