# Zip me

A note in a folder of its own, to export as a .zip from its row in the sidebar.

- It links to [[Export sampler]], which lives in another folder. In the .zip, that link becomes the sampler's web address, since the sampler isn't in it.
- It links to [[Zip me too]], which is in the same folder, so that link stays as it is and still works in Obsidian.
