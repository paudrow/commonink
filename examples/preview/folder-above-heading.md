title: The folder above a note (a trial)
---
A trial: a note in a folder shows that folder in small grey text above its heading. It's meant to be quiet. Judge whether it earns its place, since #148 took the breadcrumb out on purpose.

1. Open "Common Ink roadmap". Above the heading, in small grey text, it says "Projects" with a folder icon. The heading sits where it did before.
2. Open "Getting started". It's at the top level, so nothing shows above it.
3. Back in "Common Ink roadmap", click "Projects" above the heading. Notes opens, narrowed to the Projects folder.
4. Make a folder inside another folder, then move a note into it (Ctrl+Shift+P or ⌘⇧P, then "Move to folder…"). Above it you'll see both, like "Projects / Clients". Each part is its own link.
5. Change the note's heading. It's still renamed to match, and the folder line stays.
6. Open a second note to the side (⌘⌥\ or Ctrl+Alt+\). Each pane shows its own note's folder.
