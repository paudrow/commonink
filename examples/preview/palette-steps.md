title: Commands ask in the palette
---
A command that needs one thing from you (a name, a folder, a tag, a version) now asks for it right in ⌘⇧P, the way Raycast does, instead of sending you to the sidebar or a form. The command's name stands before the field. Enter answers, Esc (or Backspace in an empty field) goes back a step, and when it's done the palette closes and you're back where you were.

1. Open [[Pitch]] and click into the text. Press ⌘⇧P (Ctrl+Shift+P off a Mac), type `move` and press Enter. Pick a folder, or type a new name and press Enter. The note moves, and your cursor is still in it.
2. ⌘⇧P → **Star or unstar a tag…**: type `pitch`, Enter. It's under Favorites now, and the cursor never left the note.
3. ⌘⇧P → **Rename a tag…**: pick `#pitch`, type `pitches`, Enter. Try renaming it onto a tag that exists, like `start`: the next step asks whether to merge.
4. ⌘⇧P → **New contact…** needs a name, an email and a company, more than one field, so it opens the New contact dialog on the Contacts page, as before.
5. ⌘⇧P → **Restore to a named version…** on [[Pitch]]: its named versions are listed, newest first. Pick **First draft**: the note goes back to it, with Undo in the toast. **Name this version…** asks the name the same way.
6. Click a folder or a tag in the sidebar, then ⌘⇧P → **Rename folder…** or **Rename tag…**: the new name is asked in the palette too.
7. ⌘⇧P → **New folder** and **New tag** ask the name in the palette too.
8. ⌘⇧P → **New smart folder** opens the smart folder editor, the same one the + on the sidebar's Smart folders opens: rows for words, folders and tags, the query, and Share with workspace. Escape closes it and puts you back where you were before ⌘⇧P (in [[Pitch]]'s text, if that's where you were). On Notes, filter by `#pitch` and ⌘⇧P → **Save these filters as a smart folder**: the same editor, filled in with `#pitch`.
9. ⌘⇧P → **New note from template…**: pick **Standup**, then type a title (or leave it blank) and Enter.
10. Partway through any of the palette ones, press Esc: you step back to the command list, with what you'd typed.
