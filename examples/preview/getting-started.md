title: Getting started teaches by doing
---
1. Open [[Getting started]]: seven things to try, nothing ticked. It replaces the old Welcome note; the reference bits moved to [[Tips]].
2. Press ⌘K, then Esc. Back in the note, "Press ⌘K" is ticked, highlighted and tagged "Guide for you", and a toast says the guide edited the note. History shows it with the bot icon, under **AI**.
3. On the Guide card under "Watch an agent edit this note", click **Show me**. A line appears below the card, highlighted and tagged. Press ⌘Z: the line goes, and the guide ticks "Watch an agent edit this note".
4. Type `/` on a new line and pick **Timer**; type `[[` and pick a note; click ☆ in the top bar; tick a task in [[Errands to tick]]. Each box in Getting started ticks itself as you go.
5. On the "Connect your own agent" card, click **Connect an agent**: the Connected agents dialog opens with this Preview's `/mcp` address. Connect Claude to it (claude.ai: Settings → Connectors → Add custom connector) and have it add a line to any note. When its change arrives, the last box ticks itself and the guide adds a "You're set" line linking [[Tips]] and [[Overview]].
6. The last card now offers **Archive this note**. Click it: the note moves to Archive, with Undo, and the guide stops.
7. Before you finish, reword an unticked box and then do its thing: it still ticks. Each box carries a hidden `<!-- guide:… -->` marker, which shows when your cursor reaches it.
