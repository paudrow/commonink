title: GitHub cards
---
1. Open [[GitHub links]]. Each GitHub issue or pull request link on its own line is a card: an icon and pill for its state (green open, purple merged or done, red closed, grey draft or not planned), its title and number, the repo, who opened it, its comments, when it last changed, and its labels in GitHub's colors.
2. Click a card: it opens on GitHub in a new tab. Press the code button on its corner (or move the cursor onto its line): the line is still the plain URL.
3. The link inside a sentence stays a link. The last link is to a private repo, so unless the Preview has a `GITHUB_TOKEN` that can read it, it stays an ordinary link card.
4. Paste another github.com issue or PR link on a new line: it becomes a card.
5. Open **Notes** and expand the GitHub links card: the cards are drawn there too, and in an embed (`![[GitHub links]]`).
6. Switch the theme: cards follow light and dark.
