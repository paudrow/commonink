title: A calmer status bar
---
1. Open [[Getting started]], which has no code. The bar at the bottom shows the cursor position, the word count, the connection dot, the theme button and the gear. There's no **Vim keys** or **Wrap code** chip.
2. Open [[Tips]], which has code blocks: **Wrap code: on** appears. In a prose note, type ``` on a new line: the chip appears a moment later. Delete it and the chip goes.
3. Press ⌘⇧P and run **Turn vim keys on**: NORMAL and **Vim keys: on** appear. Click the chip: Vim turns off and the chip goes. Settings (⌘,) → Vim keys does the same.
