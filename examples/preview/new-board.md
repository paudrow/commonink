title: New board from the command palette
---
1. Press ⌘⇧P (Ctrl+Shift+P off a Mac) and type `board` or `kanban`. **New board** is the first command.
2. Press ↵. A new note opens with Backlog, Doing and Done columns and the cursor in its title. Type "Launch plan" and click away: the note is named after its title, like any new note.
3. On the Notes page, filter to a folder (say Projects) and run **New board** again. The board note goes into that folder, the same way the sidebar's New note does.
