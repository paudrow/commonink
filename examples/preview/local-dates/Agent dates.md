# Agent dates

An agent reads and writes dates in your time zone, the one your browser reported when the app last loaded. With none reported, it uses the workspace owner's, and failing that, UTC.

## Tasks

- [ ] Pay the electric bill due:{{date}}
- [ ] Renew the car registration due:{{date:+1d}}
- [ ] Return the library books due:{{date:-1d}}

## Things to ask your agent

- "What's on today?"
- "Add a task: call mom tomorrow"
- "Tick Pay the electric bill in Agent dates"
- "Which tasks are due tomorrow?"
