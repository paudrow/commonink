# Callouts that fold

Obsidian's callouts work too. Its names map onto GitHub's five alert types (`info` is a note, `danger` is a caution, and so on), and a `-` or `+` after the type makes one fold.

> [!faq]- How do I open this one?
> Click the triangle next to its title. It starts closed because of the `-`, and it remembers what you did, in this browser only. The file doesn't change.

> [!example]+ Starts open
> The `+` means foldable but open to begin with.
> - Lists work inside a callout
> - So do **bold**, `code` and [[GitHub markdown sampler|links]]

> [!danger] Not foldable
> Without `-` or `+`, a callout is always open, like a GitHub alert.

## A heading to link to

Hover this heading and click the link icon at its end to copy a link to it. Open the link in a new tab: the note opens scrolled here. With a split view, it opens in the pane that has this note.

Footnotes can hold longer asides[^aside]. Hover the number to read one without scrolling.
